# คู่มือจัดหน้า Ebook และไฟล์ PDF สำเร็จรูป

## ตอบคำถามก่อน
ผมไม่สามารถเข้า Canva account ของคุณหรือกดสร้างงานในบัญชีคุณได้โดยตรงถ้าไม่มีการล็อกอิน แต่ผมจัดหน้าเป็นไฟล์ HTML print-ready และ export เป็น `AI-Sales-Kit-Ebook.pdf` ให้แล้ว คุณใช้ PDF นี้ขาย/ส่งตัวอย่างได้ทันที หรือเอาต้นฉบับไปปรับต่อใน Canva ได้

## เครื่องมือที่แนะนำ

### ตัวเลือก 1: ใช้ PDF ที่จัดหน้าแล้ว
เหมาะที่สุดถ้าคุณอยากเริ่มขายเร็ว

วิธีทำ:
1. เปิดไฟล์ `AI-Sales-Kit-Ebook.pdf`
2. ตรวจชื่อสินค้า ราคา และข้อความที่อยากปรับ
3. ส่ง PDF นี้เป็นไฟล์หลัก หรือใช้เป็นตัวอย่างก่อนทำเวอร์ชัน Canva
4. ถ้าต้องแก้ layout ให้แก้ `ai-sales-kit-preview.html` แล้ว export PDF ใหม่

### ตัวเลือก 2: Canva
เหมาะที่สุดถ้าคุณอยากได้หนังสือสวยเร็ว ไม่ต้องออกแบบเองเยอะ

วิธีทำ:
1. เข้า Canva
2. ค้นหา template คำว่า "ebook", "lead magnet", "workbook", หรือ "guidebook"
3. เลือกขนาด A4 หรือ US Letter
4. ใช้สีหลัก 2 สีและสีพื้น 1 สี
5. วางเนื้อหาจาก `ai-sales-kit-ebook.md`
6. ทำกล่อง highlight สำหรับ prompt และ checklist
7. Export เป็น PDF Print หรือ PDF Standard

### ตัวเลือก 3: Google Docs
เหมาะถ้าอยากทำเร็วและแก้ง่าย

วิธีทำ:
1. เปิด Google Docs
2. วางเนื้อหา markdown โดยลบเครื่องหมาย `#`, `##`, `>`
3. ตั้ง heading ให้เป็นระบบ
4. แทรก page break ทุกบท
5. Export เป็น PDF

### ตัวเลือก 4: HTML to PDF
เหมาะถ้าต้องการ layout สะอาดและแปลงเป็น PDF จาก browser

วิธีทำ:
1. เปิดไฟล์ `ai-sales-kit-preview.html` ใน browser
2. กด Print
3. เลือก Save as PDF
4. ตั้ง margin เป็น Default หรือ None ตามที่ต้องการ

## Style Guide ที่แนะนำ

### Mood
เรียบง่าย อ่านง่าย มืออาชีพ เป็นมิตรกับแม่ค้าออนไลน์มือใหม่

### สี
- สีหลัก: น้ำเงินเข้ม `#1E3A8A`
- สีรอง: ส้ม `#F97316`
- สีพื้น: ครีมอ่อน `#FFF7ED`
- สีตัวอักษร: เทาเข้ม `#1F2937`

### ฟอนต์ Canva
- หัวข้อ: Prompt หรือ Kanit SemiBold
- เนื้อหา: Sarabun หรือ Noto Sans Thai
- ขนาดหัวข้อบท: 26-32 px
- ขนาดเนื้อหา: 14-16 px
- ระยะบรรทัด: 1.4-1.6

## โครงหน้า

### หน้า 1: ปก
ข้อความปก:

AI Sales Kit สำหรับแม่ค้าออนไลน์

ใช้ AI ช่วยตอบแชท คิดโพสต์ และปิดการขายใน 7 วัน

พร้อม Prompt, Script, FAQ และแผนโพสต์ 30 วัน

### หน้า 2: คำโปรยและเหมาะกับใคร
ใช้เนื้อหาจากช่วงต้นไฟล์ Ebook

### หน้า 3: วิธีใช้คู่มือนี้
ทำเป็น checklist 5 ข้อ

### หน้า 4: สารบัญ
ใส่บทที่ 1-10

### หน้าแต่ละบท
ใช้โครงนี้:
- หัวบทใหญ่
- คำอธิบายสั้น
- กล่อง Prompt พร้อมใช้
- ตัวอย่างคำตอบ
- Checklist หรือ Action Step

### หน้าท้าย
ใส่ CTA:

เริ่มจากสินค้า 1 ตัว
คัดลอก prompt ไปใช้
ปรับคำตอบให้เข้ากับร้าน
วัดผลจากลูกค้าจริง
