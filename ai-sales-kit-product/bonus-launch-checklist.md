# Bonus: Checklist ก่อนเปิดขาย AI Sales Kit

ใช้ checklist นี้ก่อนเริ่มขาย digital product หรือก่อนยิงแอด เพื่อให้ระบบพื้นฐานครบและลดปัญหาลูกค้าถามซ้ำ

## 1. ไฟล์สินค้า
- [ ] มีไฟล์ Ebook PDF
- [ ] มี prompt pack แยก
- [ ] มี bonus file อย่างน้อย 2-3 ไฟล์
- [ ] ตั้งชื่อไฟล์ให้ลูกค้าเข้าใจง่าย
- [ ] ทดสอบเปิดไฟล์บนมือถือแล้วอ่านได้

## 2. หน้าขาย
- [ ] Headline บอกผลลัพธ์ชัด
- [ ] Bullet บอกสิ่งที่ลูกค้าได้รับ
- [ ] มีราคาและปุ่มซื้อชัดเจน
- [ ] มี FAQ เรื่องวิธีรับไฟล์/จ่ายเงิน
- [ ] มีคำเตือนว่าไม่รับประกันยอดขาย 100%

## 3. ระบบรับเงินและส่งไฟล์
- [ ] เลือกช่องทางรับเงิน เช่น PromptPay, โอน, Gumroad, Payhip หรือระบบอื่น
- [ ] เตรียมข้อความยืนยันหลังจ่ายเงิน
- [ ] เตรียมลิงก์ดาวน์โหลด/Google Drive
- [ ] ทดสอบสั่งซื้อเอง 1 รอบ
- [ ] เช็กว่าไฟล์ดาวน์โหลดได้จากมือถือ

## 4. แชทและ FAQ
- [ ] เตรียมคำตอบราคา
- [ ] เตรียมคำตอบวิธีจ่ายเงิน
- [ ] เตรียมคำตอบหลังโอน
- [ ] เตรียมคำตอบถ้าลูกค้าดาวน์โหลดไม่ได้
- [ ] เตรียมคำตอบเรื่องขอคืนเงิน/เปลี่ยนไฟล์

## 5. แอด
- [ ] มี ad copy อย่างน้อย 3 แบบ
- [ ] มี creative อย่างน้อย 3 ภาพ/วิดีโอ
- [ ] ตั้งงบ test แบบไม่เสี่ยงเกินไป
- [ ] วัด CTR, CPC, จำนวนทัก, จำนวนซื้อ
- [ ] ปิดตัวที่ไม่เวิร์ก และขยายตัวที่มีสัญญาณดี
