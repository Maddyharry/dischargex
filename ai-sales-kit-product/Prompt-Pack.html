Prompt Pack: AI Sales Kit สำหรับแม่ค้าออนไลน์

ใช้ prompt เหล่านี้โดยแทนค่าข้อความในวงเล็บ [ ] ให้ตรงกับร้านของคุณก่อนส่งให้ AI

วิธีใช้ให้ได้ผล

1. เริ่มจากสินค้า 1 ตัวก่อน

2. กรอกข้อมูลร้านให้ชัด

3. คัดลอก prompt ไปวางใน ChatGPT, Gemini หรือ Claude

4. อ่านคำตอบทุกครั้งก่อนส่งให้ลูกค้า

5. เก็บคำตอบที่ใช้ได้ดีไว้เป็นคลังคำตอบของร้าน

1. Prompt ตอบลูกค้าถามราคา

คุณคือแอดมินร้านค้าออนไลน์ ช่วยเขียนคำตอบลูกค้าที่ถามว่า "ราคาเท่าไหร่" สำหรับสินค้า [ชื่อสินค้า] ราคา [ราคา] จุดเด่นคือ [จุดเด่น] โปรโมชันคือ [โปรโมชัน] ใช้น้ำเสียงสุภาพ เป็นกันเอง และปิดท้ายด้วยคำถามชวนสั่งซื้อ

2. Prompt ตอบลูกค้าขอส่วนลด

ช่วยเขียนคำตอบลูกค้าที่ขอส่วนลด โดยยังรักษากำไรของร้านไว้ สินค้าคือ [ชื่อสินค้า] ราคา [ราคา] โปรที่ให้ได้คือ [โปรที่ให้ได้] จุดเด่นคือ [จุดเด่น] ใช้น้ำเสียงนุ่มนวล ไม่ปฏิเสธแข็ง และพาลูกค้าไปที่ความคุ้มค่า

3. Prompt ตอบลูกค้าบอกว่าแพง

ช่วยเขียนคำตอบลูกค้าที่บอกว่าสินค้าแพง ให้เน้นคุณค่า จุดเด่น ความคุ้มค่า และความเหมาะกับลูกค้า โดยไม่กดดัน สินค้าคือ [ชื่อสินค้า] ราคา [ราคา] จุดเด่นคือ [จุดเด่น] เหมาะกับ [กลุ่มลูกค้า]

4. Prompt ตอบลูกค้าขอคิดดูก่อน

ช่วยเขียนข้อความติดตามลูกค้าที่บอกว่าขอคิดดูก่อน สำหรับสินค้า [ชื่อสินค้า] ใช้น้ำเสียงสุภาพ ไม่เร่ง ไม่กดดัน ย้ำประโยชน์หลัก [ประโยชน์] และชวนให้ถามเพิ่มถ้ายังลังเล

5. Prompt ตอบลูกค้าอ่านแล้วไม่ตอบ

ช่วยเขียนข้อความ follow up ลูกค้าที่อ่านแล้วไม่ตอบ หลังจากสนใจสินค้า [ชื่อสินค้า] ใช้น้ำเสียงเป็นกันเอง ไม่กดดัน และมีเหตุผลให้กลับมาตอบ เช่น โปรโมชัน รอบส่ง หรือสต็อก

6. Prompt ตอบลูกค้าเปรียบเทียบร้านอื่น

ช่วยเขียนคำตอบลูกค้าที่บอกว่าเห็นร้านอื่นถูกกว่า สำหรับสินค้า [ชื่อสินค้า] ให้ตอบแบบสุภาพ ไม่โจมตีร้านอื่น เน้นจุดต่างของร้านเรา เช่น [จุดเด่นร้าน] [บริการ] [การรับประกัน]

7. Prompt ตอบลูกค้าถามส่งของ

ช่วยเขียนคำตอบเรื่องการจัดส่งสำหรับสินค้า [ชื่อสินค้า] โดยบอกระยะเวลาส่ง [ระยะเวลา] ค่าส่ง [ค่าส่ง] บริษัทขนส่ง [ขนส่ง] และขั้นตอนหลังโอนเงิน ใช้น้ำเสียงชัดเจนและน่าเชื่อถือ

8. Prompt ตอบลูกค้าถามวิธีใช้

ช่วยเขียนวิธีใช้สินค้า [ชื่อสินค้า] แบบเข้าใจง่าย เป็นขั้นตอนสั้น ๆ สำหรับลูกค้ามือใหม่ พร้อมข้อควรระวัง [ข้อควรระวัง] และคำแนะนำเพิ่มเติม [คำแนะนำ]

9. Prompt ตอบลูกค้าถามว่าเหมาะกับใคร

ช่วยเขียนคำตอบว่า [ชื่อสินค้า] เหมาะกับใคร โดยแบ่งเป็น "เหมาะกับ" และ "อาจไม่เหมาะกับ" ใช้น้ำเสียงจริงใจ ไม่ขายเกินจริง และช่วยให้ลูกค้าตัดสินใจง่ายขึ้น

10. Prompt ตอบลูกค้าถามรีวิว

ช่วยเขียนข้อความส่งรีวิวให้ลูกค้าดู สำหรับสินค้า [ชื่อสินค้า] โดยสรุปรีวิวหลัก [รีวิว] และชวนให้ลูกค้าถามเพิ่มเติม ใช้น้ำเสียงสุภาพ ไม่อวดอ้างผลลัพธ์เกินจริง

11. Prompt สร้าง FAQ ร้านค้า

ช่วยสร้าง FAQ 15 ข้อสำหรับสินค้า [ชื่อสินค้า] ข้อมูลสินค้าคือ [ข้อมูลสินค้า] ให้ตอบแบบสั้น ชัดเจน สุภาพ เหมาะกับใช้ตอบลูกค้าในแชท

12. Prompt สร้างคำตอบ FAQ แบบสั้นมาก

จาก FAQ นี้ [วาง FAQ] ช่วยย่อคำตอบให้สั้นลง เหมาะกับตอบในแชทมือถือ ไม่เกิน 2-3 บรรทัดต่อคำตอบ

13. Prompt ปรับน้ำเสียงให้เป็นกันเอง

ช่วยปรับข้อความนี้ให้สุภาพ เป็นกันเอง อ่านแล้วรู้สึกเหมือนแอดมินร้านเล็กที่ดูแลลูกค้าดี แต่ยังคงข้อมูลเดิมครบ: [วางข้อความ]

14. Prompt ปรับน้ำเสียงให้ดูมืออาชีพ

ช่วยปรับข้อความนี้ให้ดูน่าเชื่อถือ มืออาชีพ กระชับ และเหมาะกับร้านค้าออนไลน์: [วางข้อความ]

15. Prompt ตรวจคำตอบก่อนส่งลูกค้า

ช่วยตรวจข้อความตอบลูกค้านี้ว่ามีจุดไหนดูแข็ง กดดัน หรือข้อมูลไม่ชัดเจนไหม พร้อมปรับให้ดีขึ้น: [วางข้อความ]

16. Prompt คิดมุมขาย 10 มุม

ช่วยแตกมุมขาย 10 มุมสำหรับสินค้า [ชื่อสินค้า] กลุ่มลูกค้า [กลุ่มลูกค้า] โดยแต่ละมุมให้ระบุ pain point, ประโยชน์หลัก, hook และ CTA

17. Prompt คิดโพสต์จากปัญหาลูกค้า

ช่วยคิดหัวข้อโพสต์ 10 หัวข้อจากปัญหาของลูกค้าที่เกี่ยวกับ [สินค้า] โดยแต่ละหัวข้อต้องเริ่มด้วย hook ที่ทำให้คนหยุดอ่าน

18. Prompt วางแผนโพสต์ 30 วัน

คุณคือ content strategist สำหรับร้านค้าออนไลน์ ช่วยวางแผนโพสต์ 30 วันสำหรับสินค้า [ชื่อสินค้า] กลุ่มลูกค้า [กลุ่มลูกค้า] โดยแบ่งเป็นโพสต์ปัญหา ให้ความรู้ รีวิว เบื้องหลัง และโปรโมชัน ขอเป็นตารางที่มีวันที่ หัวข้อโพสต์ hook สั้น ๆ และ CTA

19. Prompt เขียนโพสต์ให้ความรู้

ช่วยเขียนโพสต์ให้ความรู้เกี่ยวกับ [หัวข้อ] สำหรับลูกค้าที่สนใจ [สินค้า] เริ่มด้วย hook สั้น ๆ อธิบายแบบเข้าใจง่าย และปิดท้ายด้วย CTA ให้ทักแชท

20. Prompt เขียนโพสต์รีวิว

ช่วยเขียนโพสต์รีวิวสินค้า [ชื่อสินค้า] จากข้อมูลรีวิวนี้ [รีวิว] ให้ดูจริงใจ ไม่เว่อร์ ไม่เคลมเกินจริง และปิดท้ายชวนลูกค้าทักถามรายละเอียด

21. Prompt เขียนโพสต์โปรโมชัน

ช่วยเขียนโพสต์โปรโมชันสำหรับสินค้า [ชื่อสินค้า] โปรคือ [โปรโมชัน] หมดเขต [วัน/เวลา] ให้ดูน่าสนใจ ชัดเจน และไม่กดดันเกินไป

22. Prompt เขียนโพสต์เบื้องหลังร้าน

ช่วยเขียนโพสต์เบื้องหลังร้านเกี่ยวกับ [เรื่องที่อยากเล่า] เพื่อเพิ่มความน่าเชื่อถือและความเป็นกันเอง ให้เหมาะกับร้าน [ประเภทร้าน]

23. Prompt เปลี่ยนโพสต์ยาวเป็นโพสต์สั้น

ช่วยย่อโพสต์นี้ให้สั้น กระชับ เหมาะกับ Facebook หรือ LINE OA โดยยังคง hook จุดขาย และ CTA: [วางโพสต์]

24. Prompt เปลี่ยนโพสต์เป็นสคริปต์คลิปสั้น

ช่วยเปลี่ยนโพสต์นี้เป็นสคริปต์คลิป TikTok/Reels ความยาว 30 วินาที มี hook 3 วินาทีแรก เนื้อหากระชับ และ CTA ท้ายคลิป: [วางโพสต์]

25. Prompt ทำ caption จากรูปสินค้า

ช่วยเขียน caption 5 แบบสำหรับรูปสินค้า [อธิบายรูป] สินค้าคือ [ชื่อสินค้า] กลุ่มลูกค้า [กลุ่มลูกค้า] ให้แต่ละแบบมี hook และ CTA แตกต่างกัน

26. Prompt แคปชันสูตร AIDA

ช่วยเขียนแคปชันขายสินค้า [ชื่อสินค้า] ด้วยสูตร AIDA กลุ่มลูกค้าคือ [กลุ่มลูกค้า] จุดเด่นคือ [จุดเด่น] ราคา [ราคา] CTA คือให้ทักแชท ใช้น้ำเสียงเป็นกันเอง

27. Prompt แคปชันสูตร PAS

ช่วยเขียนแคปชันขายสินค้า [ชื่อสินค้า] ด้วยสูตร Problem-Agitate-Solution เริ่มจากปัญหา [ปัญหา] ขยายผลกระทบ แล้วเสนอสินค้าเป็นทางเลือก พร้อม CTA ให้ทักแชท

28. Prompt แคปชันแบบเล่าเรื่อง

ช่วยเขียนแคปชันขายสินค้า [ชื่อสินค้า] แบบ storytelling เริ่มจากสถานการณ์จริงของลูกค้า [สถานการณ์] แล้วเชื่อมไปที่ประโยชน์ของสินค้า ใช้น้ำเสียงอบอุ่นและจริงใจ

29. Prompt สร้าง hook 20 แบบ

ช่วยคิด hook 20 แบบสำหรับขายสินค้า [ชื่อสินค้า] ให้เหมาะกับกลุ่มลูกค้า [กลุ่มลูกค้า] โดยแบ่งเป็น hook แบบปัญหา ความรู้ รีวิว โปรโมชัน และความเข้าใจผิด

30. Prompt สร้าง CTA 20 แบบ

ช่วยคิด CTA 20 แบบสำหรับชวนลูกค้าทักแชทสั่งซื้อสินค้า [ชื่อสินค้า] ให้มีหลายอารมณ์ เช่น สุภาพ เร่งด่วน เป็นกันเอง และให้ข้อมูล

31. Prompt ปิดการขายแบบนุ่มนวล

ช่วยเขียนข้อความปิดการขายแบบนุ่มนวล สำหรับลูกค้าที่สนใจสินค้า [ชื่อสินค้า] แต่ยังไม่ตัดสินใจ ให้ย้ำประโยชน์หลัก โปรโมชัน และขั้นตอนสั่งซื้อแบบสั้น ๆ

32. Prompt ปิดการขายด้วยรีวิว

ช่วยเขียนข้อความปิดการขายโดยใช้รีวิวลูกค้าเป็นตัวช่วย สำหรับสินค้า [ชื่อสินค้า] รีวิวสำคัญคือ [รีวิว] ใช้น้ำเสียงสุภาพและไม่อวดเกินจริง

33. Prompt ปิดการขายด้วยโปรจำกัดเวลา

ช่วยเขียนข้อความแจ้งโปรโมชันจำกัดเวลา สำหรับสินค้า [ชื่อสินค้า] โปรคือ [โปรโมชัน] หมดเขต [วัน/เวลา] ให้ดูจริงใจ ไม่กดดันเกินไป และชวนลูกค้าสรุปยอด

34. Prompt สรุปยอดสั่งซื้อ

ช่วยเขียนข้อความสรุปยอดสั่งซื้อสินค้า [ชื่อสินค้า] จำนวน [จำนวน] ราคา [ราคา] ค่าส่ง [ค่าส่ง] ยอดรวม [ยอดรวม] พร้อมขอชื่อ ที่อยู่ เบอร์โทร และแนบช่องทางชำระเงิน [ช่องทางชำระเงิน]

35. Prompt แจ้งโอนเงิน

ช่วยเขียนข้อความแจ้งวิธีโอนเงินสำหรับลูกค้าที่พร้อมสั่งซื้อ โดยบอกยอดรวม [ยอดรวม] บัญชี/พร้อมเพย์ [ข้อมูลรับเงิน] และให้ลูกค้าส่งสลิปพร้อมชื่อ ที่อยู่ เบอร์โทร ใช้น้ำเสียงสุภาพ

36. Prompt แจ้งรับออเดอร์แล้ว

ช่วยเขียนข้อความขอบคุณลูกค้าหลังได้รับสลิปและข้อมูลจัดส่งแล้ว แจ้งว่าร้านจะจัดส่งภายใน [ระยะเวลา] และจะส่งเลขพัสดุให้เมื่อลงระบบ

37. Prompt แจ้งเลขพัสดุ

ช่วยเขียนข้อความแจ้งเลขพัสดุ [เลขพัสดุ] ขนส่ง [ขนส่ง] ให้ลูกค้า พร้อมขอบคุณและชวนรีวิวหลังได้รับสินค้า

38. Prompt ขอรีวิวหลังส่งสินค้า

ช่วยเขียนข้อความขอรีวิวจากลูกค้าหลังได้รับสินค้า [ชื่อสินค้า] ใช้น้ำเสียงสุภาพ ไม่บังคับ และทำให้ลูกค้ารู้สึกว่าความเห็นของเขามีคุณค่า

39. Prompt คิดโปรโมชันที่ยังมีกำไร

ช่วยคิดโปรโมชัน 10 แบบสำหรับสินค้า [ชื่อสินค้า] ราคาขาย [ราคา] ต้นทุน [ต้นทุน] โดยเน้นโปรที่ยังรักษากำไรและทำให้ลูกค้าตัดสินใจง่ายขึ้น

40. Prompt วิเคราะห์จุดคุ้มทุน

ช่วยคำนวณกำไรต่อออเดอร์จากข้อมูลนี้ ราคาขาย [ราคา] ต้นทุนสินค้า [ต้นทุน] ค่าแพ็ก [ค่าแพ็ก] ค่าส่ง [ค่าส่ง] ค่าธรรมเนียม [ค่าธรรมเนียม] ค่าแอดต่อออเดอร์ [ค่าแอด] แล้วบอกว่าควรปรับอะไรเพื่อให้กำไรดีขึ้น

41. Prompt ตั้งราคาแพ็กสินค้า

ช่วยแนะนำราคาแพ็ก 1 ชิ้น 2 ชิ้น และ 3 ชิ้น สำหรับสินค้า [ชื่อสินค้า] ราคาทุนต่อชิ้น [ต้นทุน] ค่าแพ็กและค่าส่งเฉลี่ย [ค่าใช้จ่าย] โดยให้ลูกค้ารู้สึกคุ้มและร้านยังมีกำไร

ช่วยเขียนข้อความเสนอขายเพิ่มหลังลูกค้าสนใจสินค้า [ชื่อสินค้า] โดยเสนอ [สินค้าเสริม/แพ็กใหญ่] ให้ดูเป็นประโยชน์กับลูกค้า ไม่ยัดเยียด

43. Prompt ทำข้อความ cross-sell

ช่วยเขียนข้อความแนะนำสินค้าเสริม [สินค้าเสริม] ให้กับลูกค้าที่กำลังซื้อ [สินค้าหลัก] โดยอธิบายว่าสองอย่างนี้ใช้คู่กันแล้วดีอย่างไร

44. Prompt วิเคราะห์ลูกค้าเป้าหมาย

ช่วยวิเคราะห์กลุ่มลูกค้าเป้าหมายสำหรับสินค้า [ชื่อสินค้า] โดยระบุ อายุ เพศ ไลฟ์สไตล์ ปัญหา ความกังวล เหตุผลที่ซื้อ และเหตุผลที่ยังลังเล

45. Prompt หา pain point ลูกค้า

ช่วยคิด pain point 20 ข้อของลูกค้าที่น่าจะสนใจสินค้า [ชื่อสินค้า] และจัดกลุ่มเป็นปัญหาด้านเวลา เงิน ความมั่นใจ ความสะดวก และผลลัพธ์

46. Prompt หา objection

ช่วยคิดข้อกังวล 15 ข้อที่ลูกค้าอาจมีต่อสินค้า [ชื่อสินค้า] พร้อมคำตอบสั้น ๆ ที่สุภาพและช่วยให้ตัดสินใจง่ายขึ้น

47. Prompt ทำ persona

ช่วยสร้าง persona ลูกค้า 3 แบบสำหรับสินค้า [ชื่อสินค้า] โดยแต่ละ persona มีชื่อสมมติ อายุ ปัญหา สิ่งที่ต้องการ เหตุผลที่ซื้อ และข้อความโฆษณาที่น่าจะโดนใจ

48. Prompt คิด headline โฆษณา

ช่วยคิด headline โฆษณา 20 แบบสำหรับสินค้า [ชื่อสินค้า] โดยใช้มุมปัญหา ผลลัพธ์ ความง่าย ความคุ้มค่า และโปรโมชัน

49. Prompt เขียน ad copy

ช่วยเขียนข้อความโฆษณา Facebook 5 แบบสำหรับสินค้า [ชื่อสินค้า] กลุ่มลูกค้า [กลุ่มลูกค้า] pain point [ปัญหา] จุดขาย [จุดขาย] ราคา [ราคา] และ CTA [CTA]

ช่วยตรวจข้อความโฆษณานี้ว่าเคลมเกินจริง กดดันเกินไป หรือเสี่ยงโดนปฏิเสธไหม แล้วช่วยปรับให้สุภาพ น่าเชื่อถือ และยังขายได้: [วางข้อความโฆษณา]
